# os·carwash 🚗✨

Sitio web oficial y portal estilo Link-in-bio de **os·carwash**, lavadero de autos y camionetas en Mariano Roque Alonso (Paraguay).

## 🚀 Características

- **Diseño estilo Linktree ("Lake White")**: Minimalista, limpio y optimizado para dispositivos móviles y escritorio.
- **Acceso rápido y contacto directo**:
  - 📍 Ubicación en Google Maps (Barrio Universo, frente a la Capilla San Antonio)
  - 💬 WhatsApp Principal (+595 982 571612)
  - 💬 WhatsApp Secundario (+595 981 843583)
  - 📸 Instagram oficial (`@os.carwash_`)
  - 👥 Facebook y Messenger
- **Tarifas y Servicios integrados**:
  - 🚗 Lavado de Auto: 60.000 Gs.
  - 🛻 Lavado de Camioneta: 80.000 Gs.
  - *Nota: Los precios pueden variar dependiendo de las condiciones del vehículo.*
  - Botones con mensaje directo para solicitar turnos vía WhatsApp.
- **Horarios de Atención dinámicos**:
  - Lunes a Viernes: 8:30 a. m. a 5:00 p. m.
  - Sábados: 8:00 a. m. a 6:00 p. m.
  - Domingos: Cerrado
  - Indicador en vivo de estado (*Abierto ahora* / *Cerrado*) y resaltado automático del día actual.
- **Botón para compartir perfil**: Integración con la API nativa de compartir y copia rápida al portapapeles con notificación toast.
- **Pestañas interactivas**: Filtro dinámico entre Todos, Contacto, Precios y Horarios.
- **Rápido y liviano**: Desarrollado en HTML5 y CSS3 moderno con cero dependencias externas pesadas.
